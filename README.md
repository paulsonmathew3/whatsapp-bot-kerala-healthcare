# Kerala Health WhatsApp Appointment Bot

A concept project exploring a familiar, multilingual WhatsApp-style way to help people navigate routine government-hospital appointment tasks.

- **Case study:** [Read the case study](https://paulsonmathew3.github.io/whatsapp-bot-kerala-healthcare/Kerala_Whatsapp_Bot_Case_Study.html)


## About the prototype

The interactive prototype demonstrates a proposed conversation for language selection, booking, cancellation, rescheduling, and medicine-information navigation. It is intended to make the proposed journey tangible and support discussion and testing.

**This is a prototype, not a live healthcare service.** It uses sample data and does not verify real patient identities, access live hospital availability, create real appointments, or connect to Kerala government healthcare systems. It does not provide clinical advice or emergency triage.
